# 검찰실무

검찰실무 형법 법리를 외우기 위한 학습 페이지입니다. 서버 없이 `index.html` 하나로 동작합니다.

## 구성
- **요론집**: 장 → 항목 → ○ 쟁점 순서로 법리 2,548개. 검색, 목차, 핵심어 표시, 형광펜, 표 확대
- **플래시 카드**: 질문형 앞면 / 원문 뒷면, 알아요·몰라요·북마크, 섞기, 글자 크기
- **OX 퀴즈**: 1,950문항, 약한 선지 우선 출제, 틀린 선지 다시 풀기·해설 모아보기
- 판례번호를 누르면 엘박스(lbox.kr) 판결 페이지로 이동

## 기록 저장
학습 기록(카드 상태, OX 정답률, 형광펜, 읽던 곳)은 각자 브라우저의 `localStorage`(`gs-*` 키)에만 저장됩니다.
기기를 옮길 때는 처음 화면 아래 **학습 기록 백업·복원**에서 내보내기 → 가져오기를 하세요.

## 실행
`index.html`을 브라우저로 열거나, GitHub Pages로 배포합니다.

## 출처
「검찰실무 형법 요론」(32쪽)과 「2026 COMPACT 반반형법 플러스」 각론의 보충 법리를 1~2줄로 요약한 학습용 메모입니다. 표 4개는 요론 원본 이미지입니다.
